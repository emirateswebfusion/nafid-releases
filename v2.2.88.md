## Purchase barcode label printing and return dual metrics

- Added direct barcode label printing from purchase bills in the editor, list, and detail view modal.
- New batch barcode printing modal with label quantities defaulting to purchased item counts.
- Added a "Show Price on Labels" toggle to suppress MRP and offer price from printed labels when desired.
- Smooth and hierarchical Escape key navigation to close purchase modals step-by-step.
- Preserved dual metrics (weight and piece counts) on return items across billing cart, Return Manager, database persistence, and receipts.

If an older installation stalls while updating, close Nafid normally and run the full installer once. Keep the existing shop database; do not uninstall or delete local data.
